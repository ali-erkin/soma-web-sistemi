# ⛏️ Soma Kömür Ocağı - Web Yönetim Sistemi

Maden sahası için Flask tabanlı web yönetim uygulaması.

## 🎯 Özellikler
- Kullanıcı girişi & oturum yönetimi
- Vardiya bazlı üretim takibi
- Günlük & haftalık raporlama
- SQLite veritabanı entegrasyonu
- Karanlık tema arayüz

## 🛠️ Teknolojiler
- Python, Flask
- SQLite
- HTML, CSS
- Session yönetimi

## 🚀 Kurulum
```bash
pip install flask
python app.py
```
Tarayıcıda `http://localhost:5000` aç.
